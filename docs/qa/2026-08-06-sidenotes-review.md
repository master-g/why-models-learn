# Tufte 旁注验收记录

日期：2026-08-06

范围：旁注源语法校验、共享 Markdown 管线、响应式样式、渲染试验田，以及 `lengths-and-distances` 与 `mnist-mlp-training-loop` 两篇真实词条试点。

## 结果摘要

验收结论：通过。

- 两种作者语法：编号脚注与无编号 `marginnote`。
- 两篇试点：每篇各包含 1 条编号旁注与 1 条无编号边注。
- 同步：274 篇词条与 278 张 vault 插图完成原子同步。
- 单元测试与视觉契约：118/118 通过。
- 构建：303 个页面完成静态构建。
- postbuild：`mjx-error=0`，279 个 SVG 引用与 8747 个站内引用可解析。

## 语法与同步检查

同步在写入生成产物前检查以下关系：

1. 每个脚注 ID 恰好有一个引用和一个定义。
2. 每个 `marginnote` 具有标签并紧邻普通正文段落。
3. 旁注只包含文本、强调、链接和行内数学。
4. 展示公式、表格、代码、图片、嵌套 callout、多段内容与原始 HTML 触发硬错误。
5. 单篇超过 6 条旁注或单条超过 120 个可见字符只触发密度警告。

原子同步测试预先写入哨兵产物，再提供无效旁注源。同步返回失败，哨兵产物保持不变。合法脚注定义的结构冒号已加入文案 lint 豁免，旁注试点同步不产生误报。

## 渲染结构检查

Astro 构建与测试辅助函数共用同一个 Markdown 管线。管线在 MathJax 之后把脚注和 `marginnote` 转为局部 `role="note"` 节点，再执行链接改写、部署前缀、sectionize 与 sanitize。

编号旁注具有唯一引用 ID、旁注 ID、`aria-describedby` 和返回链接。无编号边注保留作者标签并不占用编号序列。渲染后不存在尾部脚注区、残留 `marginnote` 标记、复选框或旁注交互状态。

## 浏览器四象限验收

验收视口为桌面端 1440 × 1000 和移动端 390 × 844。每个页面分别检查白色主题与黑色主题。

| 页面 | 桌面端 | 移动端 | 控制台 |
| --- | --- | --- | --- |
| `playground` | 5 条旁注均为 240 px，顺序无重叠 | 5 条旁注均为 350 px，无页面级横向溢出 | 0 条 warning/error |
| `lengths-and-distances` | 2 条旁注均为 240 px，顺序无重叠 | 2 条旁注均为 350 px，无页面级横向溢出 | 0 条 warning/error |
| `mnist-mlp-training-loop` | 2 条旁注均为 240 px，分处对应正文位置 | 2 条旁注均为 350 px，无页面级横向溢出 | 0 条 warning/error |

浅色移动旁注背景为 `rgb(245, 240, 232)`。暗色移动旁注背景为 `rgb(32, 32, 29)`，文字为 `rgb(170, 169, 161)`。桌面旁注背景透明，沿用页面纸色或黑色背景。

`playground` 的编号引用与返回链接完成双向锚点跳转。引用的 `aria-describedby` 指向对应旁注 ID。旁注中的站内链接经过部署前缀处理，数学试点中的行内公式由 MathJax 渲染。

## 正文自足性

`mnist-mlp-training-loop` 的正文已经说明训练集、测试集、epoch loss 和 batch 权重。旁注只补充验证集职责和指标口径提醒。
