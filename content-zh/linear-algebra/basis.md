向量空间的一组**基**(basis)，是一组既[张成](../linear-algebra/linear-combinations-and-span/)整个空间又[线性无关](../linear-algebra/linear-independence/)的向量。两个条件各管一件事：张成管「够」——每个向量都有配方；无关管「不浪费」——配方唯一。合起来，空间里**每个向量恰好有一份配方**，这份配方就是该向量在这组基下的坐标。本篇把前两篇的结论合流，回答三件事：怎么认一组基、基为什么不唯一、以及为什么所有基的元素个数相同——那个个数就是 [维数](../linear-algebra/dimension/)，坐标本身则由 [坐标](../linear-algebra/coordinates/) 篇展开。

## 两个条件，各管一件事

沿用例向量 $\mathbf{u} = (3, 1)$、$\mathbf{v} = (1, 2)$、$\mathbf{w} = (6, 2) = 2\mathbf{u}$，三个熟悉的组合恰好演示三个状态：

- $\{\mathbf{u}, \mathbf{v}\}$：**是基**。前两篇分别验证了它张成整个平面(任意 $\mathbf{b}$ 有配方)且无关(秩 $2 = $ 向量个数)。
- $\{\mathbf{u}, \mathbf{w}\}$：**不是基**，倒在张成上——只张成一条直线，$(4, 6)$ 这类点没有配方。条件「够」不满足。
- $\{\mathbf{u}, \mathbf{v}, \mathbf{w}\}$：**不是基**，倒在无关上——零向量有非平凡配方 $2\mathbf{u} + 0\mathbf{v} - \mathbf{w} = \mathbf{0}$，任何目标的配方都有无穷多份。条件「不浪费」不满足。

最简单的基是**标准基**：$\mathbb{R}^2$ 里 $\mathbf{e}_1 = (1, 0)$、$\mathbf{e}_2 = (0, 1)$，拼 $(b_1, b_2)$ 的配方就是 $b_1\mathbf{e}_1 + b_2\mathbf{e}_2$，存在且唯一，毫无悬念。标准基下的坐标就是分量本身，普通到让人忘记「坐标相对于基」这件事——下一节换个基，就显形了。

## 同一向量，不同基，不同坐标

取向量 $\mathbf{b} = (4, 6)$，在三组基下读它：

- 标准基：$\mathbf{b} = 4\mathbf{e}_1 + 6\mathbf{e}_2$，坐标 $(4, 6)$；
- $\{\mathbf{u}, \mathbf{v}\}$ 基：用上一篇的通解公式，$\mathbf{b} = 0.4\mathbf{u} + 2.8\mathbf{v}$，坐标 $(0.4, 2.8)$；
- $\{\mathbf{p}, \mathbf{q}\}$ 基($\mathbf{p} = (1, 1)$、$\mathbf{q} = (1, -1)$)：解 $a + c = 4$、$a - c = 6$ 得 $\mathbf{b} = 5\mathbf{p} - \mathbf{q}$，坐标 $(5, -1)$。

点还是同一个点，读数随基而变。这暴露了平时被标准基掩盖的事实：**坐标不是向量的固有属性，而是相对于基的读数**；基就是读数用的参照系。换基是表示的更换，不是向量的更换。[坐标](../linear-algebra/coordinates/) 篇把「换基换算」做成系统计算。

## 三种认法

基有两个等价刻画，加上 $\mathbb{R}^n$ 里的一个快捷判据，认基不必每次都回定义。

**极小张成集。** 基是张成的集合里再不能少一个的：从 $\{\mathbf{u}, \mathbf{v}\}$ 里去掉 $\mathbf{u}$，剩下 $\operatorname{span}\{\mathbf{v}\}$ 只是条直线，$(4, 6)$ 立即失去配方。反过来，一个张成集如果少一个还张成，被去掉的那个本就在其余的张成里——组相关。所以**张成 + 极小 = 基**。

**极大无关集。** 基也是无关的集合里再不能多一个的：往 $\{\mathbf{u}, \mathbf{v}\}$ 里加 $\mathbf{w}$，立即相关($\mathbf{w}$ 落进张成)。反过来，一个无关集如果还能再加向量保持无关，说明张成没铺满空间。所以**无关 + 极大 = 基**。

**$\mathbb{R}^n$ 快捷判据。** $\mathbb{R}^n$ 里恰好 $n$ 个向量，三个条件互相等价：无关、张成 $\mathbb{R}^n$、是基。判一个就够，而判一个只需算 [秩](../linear-algebra/rank/)：秩等于 $n$ 三者全成立，小于 $n$ 三者全不成立。

## 基不唯一，大小唯一

$\mathbb{R}^2$ 的基有无穷多组：任意两个不平行的向量都是。上一节的三组基没有哪组更「正确」——选基是选参照系，看哪组读着方便。

但所有基有一个共同点：**元素个数相同**。$\mathbb{R}^n$ 的情形一句话证完：设一组基有 $k$ 个向量，排成列。张成 $\mathbb{R}^n$ 要求列秩 $= n$，而秩不超过列数，故 $k \geq n$；无关要求秩 $= k$，而秩不超过行数 $n$，故 $k \leq n$。合起来 $k = n$。这个共同的个数就是空间的**维数**——一般向量空间(多项式、矩阵、函数)里「任意两组基同大小」的证明需要替换引理，[维数](../linear-algebra/dimension/) 篇处理；结论本篇先用：维数定义良好，不靠运气。

## 神经网络里的基

词表空间里，one-hot 向量就是标准基：第 $i$ 个词是 $\mathbf{e}_i$。embedding 层做的事是把这组标准基映成学到的向量：$\mathbf{e}_i$ 乘 embedding 矩阵，矩阵与标准基向量相乘就是取列——$E\mathbf{e}_i$ 恰好是 $E$ 的第 $i$ 列，即第 $i$ 个词的词向量。「查表」的数学形态是基向量与矩阵相乘。

换基在深度学习里是日常动作，只是不总叫这个名字。PCA 找的是与数据方差对齐的一组正交基，把坐标转到方差大的方向上；注意力里的 $W_Q$、$W_K$ 把同一批向量分别投进查询空间与键空间，相当于各换一次参照系再比较；隐藏层之间的满秩方阵，列就是一组基，乘以它就是换基。这些操作的合法性都由本篇与前几篇保证：新参照系下的读数存在且唯一，当且仅当新基确实是基。

## 失效模式与常见误区

**以为基要正交、要单位长。** $\mathbf{u} \cdot \mathbf{v} = 5 \neq 0$，$\{\mathbf{u}, \mathbf{v}\}$ 不正交也不单位长，照样是基。正交且单位长的标准正交基是计算上的奢侈品(坐标公式变成点积)，不是定义的组成部分。

**以为基唯一。** 同一空间有无穷多组基；「向量的坐标」离开基没有意义，说坐标必须说在哪组基下。

**只查一个条件就当基。** 只张成($\{\mathbf{u}, \mathbf{v}, \mathbf{w}\}$，配方不唯一)或只无关($\{\mathbf{u}, \mathbf{w}\}$，点没配方)都不够；两个条件一个管存在、一个管唯一，缺一不可。

**以为基的大小可以不同。** 同一空间的所有基元素个数相同(否则「维数」一词无意义)；$\mathbb{R}^n$ 里就是 $n$ 个，多一个相关、少一个不张成。
