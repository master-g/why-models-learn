一组向量 $\mathbf{v}_1, \dots, \mathbf{v}_k$ **线性无关**(linearly independent)，如果零向量只有一份平凡的配方：

$$
c_1\mathbf{v}_1 + \cdots + c_k\mathbf{v}_k = \mathbf{0} \implies c_1 = \cdots = c_k = 0
$$

反过来，只要存在一组不全为零的系数让组合等于零，这组向量就**线性相关**(linearly dependent)。上一篇 [线性组合与张成](../linear-algebra/linear-combinations-and-span/) 回答的是「能不能拼出」；本篇回答配套的另一问：「配方唯不唯一」，也就是组内有没有冗余。这个冗余正是 [秩](../linear-algebra/rank/) 数的东西；而一组既张成又无关的向量，就是下一篇的 [基](../linear-algebra/basis/)。

## 定义与三个例子

沿用例向量 $\mathbf{u} = (3, 1)$、$\mathbf{v} = (1, 2)$、$\mathbf{w} = (6, 2) = 2\mathbf{u}$。

**$\{\mathbf{u}, \mathbf{v}\}$ 无关。** 零向量的配方 $a$、$c$ 要满足 $3a + c = 0$ 与 $a + 2c = 0$。上一篇推出的通解公式 $a = (2b_1 - b_2)/5$、$c = (3b_2 - b_1)/5$ 代入 $\mathbf{b} = \mathbf{0}$，得 $a = c = 0$——除了全取零，没有别的办法拼出零向量。

**$\{\mathbf{u}, \mathbf{w}\}$ 相关。** 因为 $\mathbf{w}$ 是 $\mathbf{u}$ 的两倍，配方 $(2, -1)$ 给出 $2\mathbf{u} - \mathbf{w} = \mathbf{0}$，系数不全为零。

**$\{\mathbf{u}, \mathbf{v}, \mathbf{w}\}$ 相关。** 上一篇见过，$(7, 4)$ 在这组里有 $(2, 1, 0)$、$(0, 1, 1)$ 两份配方；两份相减得 $(2, 0, -1)$，直接验证：

$$
2\mathbf{u} + 0\mathbf{v} - \mathbf{w} = (6, 2) + (0, 0) - (6, 2) = \mathbf{0}
$$

三个例子的信息一致：相关组里总有多余的向量，它的系数可以在配方之间「挪来挪去」，于是配方不唯一，零向量也有了非平凡的拼法。

## 为什么定义只查零向量

判定「配方唯一」听起来要检查无穷多个目标向量，定义却只要求查 $\mathbf{0}$ 一个。原因是一个小小的引理：**零向量的配方唯一，当且仅当每一个目标的配方都唯一。**

证明两个方向各一行。设 $\mathbf{b}$ 有两份不同的配方 $\mathbf{c}$ 与 $\mathbf{c}'$，把它们相减：$(c_1 - c'_1)\mathbf{v}_1 + \cdots + (c_k - c'_k)\mathbf{v}_k = \mathbf{b} - \mathbf{b} = \mathbf{0}$，系数不全为零——零向量有了非平凡配方。反过来，若零向量有非平凡配方 $\mathbf{d}$，而 $\mathbf{b}$ 有某份配方 $\mathbf{c}$，那么 $\mathbf{c} + \mathbf{d}$ 是 $\mathbf{b}$ 的另一份配方。

所以零向量是全部目标的代表：查它一个，等于查了所有。

## 判定：消元与秩

定义里的条件是一个齐次方程组：把 $\mathbf{v}_1, \dots, \mathbf{v}_k$ 排成矩阵 $A$ 的列，配方 $\mathbf{c}$ 要满足 $A\mathbf{c} = \mathbf{0}$。按 [高斯消元](../linear-algebra/gaussian-elimination/) 的结论：

- 消元后**没有自由变量**(每列都是主元列)，唯一解是 $\mathbf{c} = \mathbf{0}$，向量组**无关**；
- 消元后**有自由变量**，自由变量任取非零值就得到非平凡解，向量组**相关**。

用 [秩](../linear-algebra/rank/) 重说：秩是主元列的个数，所以 **$k$ 个列向量无关，当且仅当秩等于 $k$**。验证三个例子：列排 $\{\mathbf{u}, \mathbf{v}\}$ 秩 $2 = k$，无关；$\{\mathbf{u}, \mathbf{w}\}$ 秩 $1 < 2$，相关；$\{\mathbf{u}, \mathbf{v}, \mathbf{w}\}$ 秩 $2 < 3$，相关。

一个立刻的推论：**$\mathbb{R}^n$ 里任意 $n + 1$ 个向量必相关**。齐次方程组此时有 $k = n + 1$ 个未知数、只有 $n$ 个方程，未知数多过方程，消元必有自由变量，非平凡解跑不掉。平面上放不下三个互不冗余的方向；$\mathbb{R}^3$ 里四个向量也必有冗余。这为「维数 = 无关向量的最大个数」埋下了直觉，正式定义在 [维数](../linear-algebra/dimension/) 篇。

## 几何：方向有没有冗余

低维情形，无关与相关有直观的几何面孔。

**一个向量。** 单独一个向量无关，当且仅当它非零——因为 $c\mathbf{v} = \mathbf{0}$ 在 $\mathbf{v} \neq \mathbf{0}$ 时只有 $c = 0$。而零向量自己，$1 \cdot \mathbf{0} = \mathbf{0}$ 就是非平凡配方。由此，**任何含零向量的组必相关**：给零向量配系数 $1$，其余配 $0$。

**两个向量。** 相关当且仅当平行(一个是另一个的倍数)：$\mathbf{u}$ 与 $\mathbf{w} = 2\mathbf{u}$ 共线，有非平凡配方 $2\mathbf{u} - \mathbf{w} = \mathbf{0}$；不平行的 $\mathbf{u}$ 与 $\mathbf{v}$，一个沿 $\mathbf{u}$ 方向的非零位移，用 $\mathbf{v}$ 方向的位移永远补不回来，组合为零只能双双取零。

**三个向量($\mathbb{R}^3$)。** 相关当且仅当共面：$\mathbf{p} = (1, 0, 0)$、$\mathbf{q} = (0, 1, 0)$、$\mathbf{s} = (2, 3, 0)$ 里，$\mathbf{s} = 2\mathbf{p} + 3\mathbf{q}$ 躺在前两个张成的 $xy$ 平面里，$2\mathbf{p} + 3\mathbf{q} - \mathbf{s} = \mathbf{0}$。注意三个向量相关时，未必有谁是谁的倍数——倍数只是两个向量情形的特例。

## 神经网络里的线性无关

权重矩阵的列相关，意味着有效容量打折。[秩](../linear-algebra/rank/) 篇的瓶颈结论换成本篇语言：全连接层的输出方向由列张成决定，列里每多一个冗余，参数就多花一份而表达力不增。低秩因子化([LoRA](../finetuning/lora/))利用的正是这个现象的反面——很多层的权重矩阵实际秩远小于维度，相关的列不需要各自独立的参数。

特征工程里，两个特征若一个能由另一个线性表出(身高用厘米与英寸各存一份)，模型要多学一份参数去承载同一份信息，数据不足时还会把噪声当成两者的差来学。去掉冗余特征，就是手工做了一次线性无关化。

词向量的各个维度，设计上希望承载彼此独立的信息。训练出来的 embedding 不保证严格无关，但维度之间的相关性高低，是衡量表示效率的一个朴素指标：高度相关的维度群，说明模型没有用完分配给它的方向。

## 失效模式与常见误区

**把无关当成垂直。** 正交必无关(点积为零的向量不可能平行或互为组合)，但无关不必正交：$\mathbf{u} \cdot \mathbf{v} = 3 \times 1 + 1 \times 2 = 5 \neq 0$，$\mathbf{u}$ 与 $\mathbf{v}$ 夹角不是直角，它们照样无关。无关只要求「不在彼此的张成里」，远比垂直宽松。

**两两无关就以为整体无关。** $(1, 0)$、$(0, 1)$、$(1, 1)$ 里任取两个都不平行，两两全部无关；但 $(1, 0) + (0, 1) - (1, 1) = \mathbf{0}$，三个一起相关。无关是整个组的性质，不能拆成 pairwise 检查。

**以为判相关必须找到「谁是谁的倍数」。** 倍数关系只是两个向量情形的特例。上面 $(1, 1)$ 不是 $(1, 0)$ 或 $(0, 1)$ 的倍数，相关照样成立——它落在另两个的张成里。一般判据回到定义：零向量有没有非平凡配方，也就是消元后有没有自由变量。

**忘记零向量这个特例。** 判无关时漏查「组里是否含零向量」：含零向量的组直接相关，不用再消元。
